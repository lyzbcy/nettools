# 操作日志与反馈

现状：实现中。负责人：捞鱼工作室。更新时间：2026-10-10。

一级“操作日志”和“遇到问题反馈”入口。长动作展示当前步骤与耗时；日志可复制、清空，持久文件轮转避免无限增长。默认记录操作类别与状态，不记录完整系统输出、内网配置、凭据或文件内容。

用户主动提交时发送软件名、版本、分类和留言。日志附件默认勾选，可预览并取消；送出前再次脱敏。软件规范指定的企业微信通道在主进程配置，渲染端不获取机器人凭据。网络失败保留用户留言并允许重试，不自动后台重复发送。

不声称未经检查的原始日志“没有任何敏感信息”；反馈预览展示实际将发送的内容。开发验收不得向真实群发送测试消息。
