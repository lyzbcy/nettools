# 打包与软件中心交付

现状：双平台候选包准备中。负责人：捞鱼工作室。更新时间：2026-10-10。

Mac 输出 arm64 / x64 独立 ZIP、DMG；ZIP 包含完整 .app。Windows 输出 x64 ZIP 与安装器，ZIP 根目录固定 LaoyuNetTools.exe，依赖与许可证完整。安装器以主题一致的图形界面选择位置，优先非系统盘，可自定义，快捷方式由用户决定。

稳定产品 ID nettools，发布仓库 lyzbcy/nettools。软件中心目录、图标、平台资源、安装识别及准备规则同步登记；新增识别必须随客户端发布。launcher-adapter.json 记录实际最终包 SHA，运行共享适配脚本严格自查。Mac 接入与 Windows 接入分别验收。

沿用原创飞天图标，并在共享 logo-registry.json 登记来源和哈希。未配 Developer ID / Windows 签名时如实说明安装提示；不能靠删除所有隔离标记作为“已签名”。

发行顺序：验证最终包→上传不可变版本包→公网下载核验→更新元数据→同步原介绍页→回读全文与备份。保留原网址和其他平台版本。当前尚未发布 5.0.0，所有候选结果保存在 verification/。

打包配置在目录包与 NSIS 两次构建前分别进行深复制，避免固定 electron-builder 对 `files` 归一化时污染下一次配置。`test/package.test.cjs` 使用生产配置和真实固定 builder 连续归一化两次，本机 4/4 通过；不下载运行时或执行打包。CI 先运行不依赖工具链的核心测试，仅在精确缺少 electron-builder 时跳过这一项，安装锁定依赖后在三个平台任务中再次执行完整包测试；已安装依赖的解析或运行错误仍然失败。正式完整构建及安装版验收由该后续 CI 提供，不能用此纯配置测试替代。
