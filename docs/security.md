# 权限与网络恢复

现状：5.0.0 权限加固与独立审查通过，真实平台助手安装、DNS 缓存刷新和撤销已有证据。负责人：捞鱼工作室。更新时间：2026-10-11。

诊断和检查不需要管理员权限。无人值守修复需用户明确安装对应平台授权，用户可撤销。未授权时守护返回分类错误；普通后台检查不自动弹权限窗口。

特权层只接受固定 action，独立验证 IP、CIDR、域名、服务与接口。系统调用使用固定程序和独立参数，每个必要步骤失败立即报告。安装目录与恢复快照需要拒绝符号链接、检查所有权和权限，使用原子替换与版本核验。

更改 DNS、代理和 VPN 分流前必须成功保存原始状态；重复操作不覆盖待恢复快照。撤销恢复原服务与原 resolver 内容。读取失败不是“空配置”；恢复失败不能提示成功。自动续租只对明确 DHCP 的物理接口执行，静态配置保持。

重启由主进程守护会话控制，不放进渲染通用动作入口。默认关闭、显式启用、取消和最后网络复查均在主进程实施。

Windows 授权任务的结果与状态查询并非同一时刻：worker 可能在主进程读到“无结果”后、任务状态查询返回 Ready 前完成原子写入。主进程确认 Ready/Disabled 后再读取一次当前 nonce 的结果；缺失、畸形、外来 nonce 仍失败，取消或既有 I/O/启动错误仍优先，Ready 本身不能代表成功。CI 在卸载授权前被动保留当前 SID 的固定 flush-dns 任务状态、principal/action、grant/request/result 及脚本哈希；拒绝链接和超大原文，不改变任务、网络配置或 ACL。该竞态已由实际生产函数的内存时序回归复现；不能据此断言此前丢失现场的每一次 CI 失败均由此造成。
