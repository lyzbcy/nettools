# 双平台架构

现状：统一桌面壳实现中。负责人：捞鱼工作室。更新时间：2026-10-10。

Electron 主进程负责定时保活、操作互斥、设置、日志、系统通知和更新。渲染页面只显示状态并通过固定 preload API 请求动作，没有 Node 权限或远端脚本。关闭到托盘不停止主进程；明确退出停止守护。

Mac 原生层使用 Swift 执行 macOS 命令；Windows 使用固定 action 的系统适配层。IPC 和平台入口均独立校验参数，拒绝未知 action。主进程传递取消信号，系统调用限制输出和耗时，失败不假报成功。

候选版本源 `package.json`，各平台包与应用版本同源。个人配置与日志独立于安装目录，不被更新覆盖。旧 Mac 公司配置保留并明确迁移；不把旧自动重启开关迁移为新默认设置。
