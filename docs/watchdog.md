# 网络保活

现状：5.0.0 核心与独立审查通过，三平台安装版验收完成。负责人：捞鱼工作室。更新时间：2026-10-13。

保活默认关闭，检查间隔默认 30 分钟。支持常用间隔和 1–1440 分钟整数。启用后立即检查；健康时按选择间隔继续。

故障修复从确认异常开始计时，不受正常检查间隔影响，最长五分钟。按问题类别选择修复，每步后重新检查；健康后结束本轮。每个系统动作有独立超时。授权缺失时报告不能自动修复，不反复弹密码窗口。

五分钟后仍异常，默认停止本轮，不重启，等待下次定期检查。用户可明确开启超时自动重启；到期先复查，仍异常才开始 60 秒可取消提醒，执行前再次复查。取消、关闭、改变策略、睡眠或恢复使旧会话失效；每进程最多重启一次，重启标记防止下一次启动循环重启。

核心通过依赖注入测试计时、并发和取消；不在测试中执行真实电脑重启。Mac 两种芯片和 Windows x64 的安装版设置持久化、正常升级和故障回滚保留了 17 分钟配置及安全开关。真实平台执行和运行范围分别写入 roadmap.md。重启后继续运行需要另行启用“开机运行”；防循环标记会使下一次启动的自动重启策略回到关闭状态。

5.0.1候选仅补守护检查日志：按业务 ok 记状态，并经控制器保留固定 issue；RPC异常/超时记录失败和错误码，取消的过期结果不写成功日志。修复选择仍使用原检查结果，不用日志分类决定动作；30分钟、五分钟、默认无动作及60秒可取消倒计时保持不变。单一HTTPS站点的健康结果有站点/地区可达性边界，补充公网IP失败不独立判为断网；本次不增加探测源。
