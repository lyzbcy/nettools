# 网络保活

现状：核心实现与独立审查中。负责人：捞鱼工作室。更新时间：2026-10-10。

保活默认关闭，检查间隔默认 30 分钟。支持常用间隔和 1–1440 分钟整数。启用后立即检查；健康时按选择间隔继续。

故障修复从确认异常开始计时，不受正常检查间隔影响，最长五分钟。按问题类别选择修复，每步后重新检查；健康后结束本轮。每个系统动作有独立超时。授权缺失时报告不能自动修复，不反复弹密码窗口。

五分钟后仍异常，默认停止本轮，不重启，等待下次定期检查。用户可明确开启超时自动重启；到期先复查，仍异常才开始 60 秒可取消提醒，执行前再次复查。取消、关闭、改变策略、睡眠或恢复使旧会话失效；每进程最多重启一次，重启标记防止下一次启动循环重启。

核心通过依赖注入测试计时、并发和取消；测试不实际修改网络或重启电脑。真实平台执行和运行范围分别写入 roadmap.md。
